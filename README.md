# massing-animations

A 16:9 widescreen architectural **massing (gubahan massa)** concept diagram animation, built with [Three.js](https://threejs.org/) in a single self-contained HTML file.

## View it

Open **`index.html`** in any web browser (no install, no build step). The animation plays on a loop.

Or enable **GitHub Pages** (Settings → Pages → deploy from `main`) to view it live at a URL.

## What it shows

A locked isometric camera over a light-gray urban site ("Jalan Mutiara Raya"), animating a 6-step form-finding sequence with sequential upper-left captions:

1. **Massa dasar bangunan** — white base mass extrudes up
2. **Penyesuaian batas massa mengikuti batas GSB** — red dashed GSB setback lines + yellow arrows push the volume back
3. **Pengurangan massa di bagian tengah (void)** — downward arrow carves a center void (mass turns coral-red)
4. **Pemotongan massa atas untuk membentuk atap** — translucent ghost + arrow slice the top into an angled roof
5. **Pemotongan sisi kiri massa untuk membentuk balkon & penambahan massa untuk menyempurnakan atap** — left-side balcony cut + roof addition
6. **Gubahan massa akhir** — final articulated form

## Make a video

Screen-record the browser window (Windows: `Win+G`; macOS: `Cmd+Shift+5`; or [OBS Studio](https://obsproject.com/)) to export a Short/clip.
